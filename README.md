# Desafio Laboratório 1 - pt-BR.
Esse projeto foi desenvolvido durante o primeiro semestre do curso de Análise e Desenvolvimento de Sistemas, na disciplina de Laboratório 1.

O software foi criado em Java para exercitar conceitos de programação orientada a objetos por meio do gerenciamento de lojas, produtos e informações de um shopping.

## ✅ Principais aprendizados
O projeto possui as seguintes funcionalidades e conceitos:

* Cadastro de lojas e produtos pelo terminal.
* Armazenamento de endereço e data de fundação das lojas.
* Cadastro da data de validade dos produtos.
* Verificação de validade dos produtos.
* Validação de datas e identificação de anos bissextos.
* Gerenciamento do estoque de produtos de uma loja.
* Inserção e remoção de lojas em um shopping.
* Uso de herança para representar diferentes tipos de loja.
* Contagem de lojas por categoria.
* Identificação da loja de informática com o seguro mais caro.

## 🏬 Tipos de loja
O projeto possui classes específicas para diferentes categorias:

* **Alimentação** - Armazena a data do alvará.
* **Bijuteria** - Armazena a meta de vendas.
* **Cosmético** - Armazena a taxa de comercialização.
* **Informática** - Armazena o valor do seguro de eletrônicos.
* **Vestuário** - Informa se a loja possui produtos importados.

## 🚀 Começando
Essas instruções permitirão que você obtenha uma cópia do projeto em operação na sua máquina local para fins de desenvolvimento e teste.

## 📝 Como executar o software
Para executar o sistema, instale o Java Development Kit (JDK) e abra o terminal na pasta principal do projeto.

Compile os arquivos usando o comando:

```bash
javac *.java
```

Em seguida, execute a classe principal:

```bash
java Principal
```

Também é possível executar a classe `Principal.java` diretamente por meio da sua IDE.

## 🔨 Como foi feito
O software foi desenvolvido usando Java e conceitos de orientação a objetos, como classes, objetos, encapsulamento, herança, arrays e sobrescrita de métodos.

***1*** - Instale o JDK (link disponível no trecho "Construído com"). <br>
***2*** - Instale a sua IDE de preferência. <br>
***3*** - Abra o projeto na IDE ou acesse a pasta principal pelo terminal. <br>
***4*** - Execute o comando ```javac *.java``` para compilar os arquivos. <br>
***5*** - Execute o comando ```java Principal``` para iniciar o programa. <br>

# Laboratory 1 Challenge - en-US.
This project was developed during the first semester of the Systems Analysis and Development course for the Laboratory 1 subject.

The software was created in Java to exercise object-oriented programming concepts through the management of stores, products, and shopping mall information.

## ✅ Main Learnings
The project provides the following features and concepts:

* Registration of stores and products through the terminal.
* Storage of store addresses and foundation dates.
* Registration of product expiration dates.
* Product expiration checks.
* Date validation and leap year identification.
* Store inventory management.
* Addition and removal of stores in a shopping mall.
* Use of inheritance to represent different store types.
* Store count by category.
* Identification of the computer store with the most expensive insurance.

## 🏬 Store Types
The project provides specific classes for different categories:

* **Food** - Stores the business license date.
* **Jewelry** - Stores the sales target.
* **Cosmetics** - Stores the marketing fee.
* **Computer store** - Stores the electronics insurance value.
* **Clothing** - Indicates whether the store sells imported products.
